## The mark

`radii-mark.svg` — one corner of an orb web. Four radii across an exact right angle at 0°,
30°, 60° and 90°, every one 46 units long, crossed by two passes of spiral. The spiral is
**straight chords, not arcs**, because a thread can only be strung in a straight line
between two radii; that one detail carries the web, so the rest is left out. Equal lengths
across a right angle put the bounding box at 50.9 × 50.9 — square, so the mark drops into an
avatar or a favicon without nudging.

| File | Use |
|---|---|
| `radii-mark.svg` | Primary. Strokes are `currentColor`, hub is Reach. |
| `radii-mark-mono.svg` | Fully `currentColor`, hub included. One-colour print, terminals, engraving. |
| `favicon.svg` | Ink tile, mark at 84% with the stroke thickened to 4.4. Browser tabs, GitHub avatar. |
| `ascii/` | Terminal cuts, generated by `scripts/gen-ascii-mark.py` — see [`ascii/README.md`](ascii/README.md). |

**Clear space:** one hub diameter (7 units in the 64-unit viewBox) on every side.
**Minimum size:** 24px for `radii-mark.svg`; below that the 3-unit stroke falls under a
pixel, so use `favicon.svg`.
**Don't:** add a second stroke weight, thicken the spiral relative to the radii, curve the
spiral into arcs, even out the 30° steps, or tint anything but the hub.

## Wordmark

`radii` set in **Space Grotesk 500**, tracking −0.02em, lowercase always, untinted. At 700 the
word out-weighed the hairline mark; at 500 they sit at the same optical density.

Technical and terminal text: **JetBrains Mono**.

## Palette

The signal colours are reachability states, not decoration — the same three colour the
crawl graph, the CLI and the mark.

| Token | Hex | Role |
|---|---|---|
| Reach | `#16C79A` | primary · reachable |
| Reach (on light) | `#0E9E7D` | primary, darkened for contrast on Paper |
| Severed | `#F2674A` | path down · error |
| Unknown | `#7C8B93` | unprobed · stale |
| Ink | `#0B0F12` | ground |
| Surface | `#121A1E` | panels, terminal |
| Line | `#1B262C` | hairlines, borders |
| Paper | `#F4F6F4` | light ground, body text on Ink |

Reach on Paper clears 3:1 only at 24px and above — headings and marks, never body copy.
Use Reach (on light) for anything smaller.
